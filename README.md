# 🇹🇳 SaaS Gestion d'Entreprises en Tunisie

> Second Brain d'Anis Habib — Automatisation Cloud 24h/7j

## 🎯 Vision
Application SaaS complète pour la **création et gestion d'entreprises en Tunisie** :
- Création SARL, SA, SUARL
- Gestion fiscale (TVA, IS, IRPP)
- Démarches administratives automatisées
- Tableau de bord dirigeant

## 🤖 Automatisations GitHub Actions (Cloud 24h/7j)
| Workflow | Fréquence | Sortie |
|----------|-----------|--------|
| 🎨 Design Graphique | Daily 10:00 | Telegram + Obsidian |
| 💻 Coding (Python/CSS/HTML) | Daily 10:30 | Telegram + Obsidian |
| ⚖️ Légal & Fiscal Tunisie | Daily 11:00 | Telegram + Obsidian |
| 🚀 Dev SaaS | Weekly Mon 09:00 | Code + Telegram |

## 🚀 Stack
- **Frontend**: HTML/CSS/JS — GitHub Pages
- **Backend**: Python Flask — Railway.app
- **DB**: Supabase (PostgreSQL)
- **IA**: Claude/Gemini via OpenRouter

## 📦 Déploiement
Automatique via GitHub Actions à chaque push sur `main`.
